⚙️ Cài đặt Google Apps Script (5 phút)

1
Tạo Google Sheets mới. Hàng 1 đặt tiêu đề: Timestamp | Tên | Mã NV | Kho | Loại ca | Giờ | Ngày | Ghi chú
2
Vào Extensions → Apps Script, xoá code cũ, dán code từ file apps-script.js đi kèm.
3
Nhấn Deploy → New deployment → Web App. Chọn Execute as: Me và Who has access: Anyone. Copy URL.
4
Dán URL vào ô API phía trên. Dấu chấm sẽ chuyển xanh = kết nối OK.
5
Tạo QR code từ link file HTML này (host trên GitHub Pages, Netlify, hoặc Google Drive). In dán tại cổng kho.
Chấm công thành công!
